HQ9+ is an esolang created by Scott Feeney in 2001. The commands are:  
-H, which prints "Hello, World!",  
-Q, which prints the source code of the program,  
-9, which prints the 99 bottles of beer song,  
-+, which increments an accumulator that can't be interacted in any way.  
Yeah, these are all the commands.
